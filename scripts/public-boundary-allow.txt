# Allowlist for the content scan in scripts/check-public-content.sh.
#
# One deliberate exception per line, four TAB-separated fields:
#   <path>	<class>	<line ERE | line-sha256:<hex>>	<reason>
# - path: exact tracked path (no globs).
# - class: a scan class (home-path, vault-deep-path, plan-id, token-*, private-key).
# - line ERE: POSIX ERE (git grep -E) run against the flagged line. It exempts a
#   hit only where one of its matches OVERLAPS the flagged match, so pin it to
#   the hit and its context, never to the bare pattern class.
# - line-sha256:<64 lowercase hex>: exempts only a line whose full text (its
#   bytes without the newline) has this sha256, i.e. exactly one line content.
#   Compute it with:
#     git cat-file blob :<path> | sed -n '<N>p' | tr -d '\n' | shasum -a 256
#   Use it where an ERE would have to wildcard a name or an id.
# - reason: why the hit is not a leak. "pending operator" marks an entry that
#   waits on an operator decision to change the content instead.
#
# Write any literal that the scan would flag in bracket form ([s]k-ant-,
# /[U]sers/, [P]RIVATE) so the entry does not trip the scan itself. Never
# write a real name, id or secret here; pin by context instead.
# An entry that no longer matches anything fails the scan: remove it.
# A home path whose name is the current OS user (or is listed in
# MINNI_BOUNDARY_FORBIDDEN_NAMES) fails whatever this file says.
